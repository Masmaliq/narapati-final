# Narapati News Network

Premium editorial website for Narapati News Network (NNN), built with Next.js App Router, TypeScript, and an embedded Sanity Studio at `/studio`.

## Getting Started

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env.local` and fill in your Sanity project values.
3. Run `npm run dev`.
4. Visit `http://localhost:3000` for the site and `http://localhost:3000/studio` for Sanity Studio.

The site includes graceful editorial sample data so the pages render before a Sanity project is connected.
